# Custom Campaign Tools
Allows Modders to add their own Campaign functionality to their Marrow Campaigns.

# Looking for the SDK?
### Find the CustomCampaignTools SDK Here: [CustomCampaignTools.SDK](https://github.com/EvroDeveloper/CustomCampaignTools.SDK)

## Build Instructions (only for genius)
Run `./build.sh` (or `./build.sh Release`) to build and install `CustomCampaignTools.dll` on a connected, authorized Quest 3 at `/sdcard/MelonLoader/com.StressLevelZero.BONELAB/Mods/`. The script uses `adb` from your `PATH`; set `ANDROID_SERIAL` if more than one Android device is connected. Set `SKIP_QUEST_INSTALL=true` to build without deploying to the headset.
